# 判一句 · 考研英语一阅读 · 整篇训练

不做题海。一篇 5 题，一次练完一整套思路。

**纯静态站点**，无后端、无登录、无构建。记录存在浏览器 localStorage。

---

## 流程（按你的实际做题习惯设计）

```
① 通读全文          ← 不给题目，先读
   ↓
② 写一句主旨        ← 不写不让进下一步
   ↓
③ 第 1 题：判题型   ← 老周问你，你选
   ↓
④ 定段位            ← 点出依据在第几段，对了才亮出依据句
   ↓
⑤ 自己选答案        ← 选完直接下一题，不告诉你对错
   ↓ （重复 ③④⑤ × 5）
⑥ 5 题全做完 → 统一结算   ← 逐题对错表 + 你写的主旨回看
   ↓
⑦ 只复盘错题        ← 正确答案 → 依据句 → 替换对 → 三个错项贴标签
```

### 为什么这么排

**你的原话：「第三关是不是有点提前了，这样不就直接知道答案了」——完全正确。**

上一版把「给三个错项贴标签」放在答题前，贴完三个就只剩一个没贴，答案自动暴露。那是用排除法猜答案，正好绕开了要练的能力。

现在排错项**只在复盘里出现**，而且是在你已经答完、已经看到正确答案之后。它是**验证**，不是**排除**。

**「要有全文章」** —— 现在给完整全文，7 段都在，你先读。

**「一套题里所有题都要练到」** —— 5 题全做完才结算，中途不跳题、不提示对错。

**「先用技巧把握文章主旨，之后根据主旨来做题」** —— 所以第 ② 步强制写主旨。写不出就写"没读懂"——那也是判断。

## 老周（NPC 助导）

一个话不多的退役阅卷老师。**只问不答。**

| 关卡 | 老周做什么 |
|---|---|
| 判题型 | 让你从 6 个题型里选。选错告诉你"不是这个"，再选 |
| 定段位 | 让你点段落号。点错提示"往前/往后看"。对了才亮出依据句 |
| 作答 | 什么都不说。**选完就走，不给对错** |
| 拦偷懒 | 三关没过就点选项 → 摇一下 + "先别选" |
| 提示 | 6 格，一次一格。**第 3 关的提示只帮到"找替换"，绝不给答案** |

## 复盘（只对错题）

顺序是固定的，不能调：

1. 题干 + 四个选项（标出你选的、正确的）
2. **依据句**（原文那一句，带段号）
3. **替换对**（原文哪句 ↔ 正确答案哪个词）
4. **三个错项各贴一个标签**

七个官方标签：`无中生有` `与原文相反` `偷换概念` `过度推断` `张冠李戴` `以偏概全` `答非所问`

贴错会告诉你"不对，再想"；贴对才给这类错的解释。

## 三条能力

全部用**一次就对的比例**，不用点击次数：

| 指标 | 怎么算 |
|---|---|
| 判题型 | 第 1 关第一次就选对题型的比例 |
| 定段位 | 第 2 关第一次就指对段落的比例 |
| 排错项 | 复盘贴标签一次就贴对的比例 |

加一张**错因分布图**：哪一格最高就是你最该练的那一格。

## AI 教练（可选）

不填 API Key 也能用，只是少了对话引导。

### 它在哪出现

| 位置 | 做什么 |
|---|---|
| 通读后的四步 | 每步先讲方法，你答完可以「问教练」追问 |
| 写完主旨 | 「让教练看看我写的」——只诊断，不给范文 |
| 做题时 | 每道题底部「问教练」，按你当前卡在哪一关给引导 |

### 它绝不给你答案

这不是靠提示词约束的。`aiGuideQuestion()` 构造请求时**只读 `options` / `num` / `stem`**，
完全不碰 `answer` / `distractors` / `pairs`。模型物理上拿不到答案，所以不可能泄露。

只有复盘阶段（答案已公开）才把答案传给模型。

### 怎么配

首页 → AI 教练 → 填三项：

- **Base URL**：OpenAI 兼容接口，末尾不要带 `/chat/completions`
- **API Key**：只存你浏览器的 localStorage
- **模型**：接口支持的名字

点「测试连通」，通了再开开关。

### 抓主旨的四步

不是让你空写一句。前面铺了四步：

1. **看首段和末段** —— 作者把结论放这两处
2. **看每段第一句** —— 段落主题句八成在第一句
3. **找转折词** —— but / however / yet 后面才是真意
4. **看态度** —— 支持、批评、担忧还是中立

每一步先给你方法，你要写下自己的答案才能进下一步。四步走完，笔记会摆在你面前，帮你合成主旨。

### 做题时能看原文

这是必须的——不给原文等于不让你回去找依据。

- 做题页顶部有「看原文」，随时展开抽屉，7 段全在
- 定位成功后会亮出依据句，旁边有「看整段」，点开抽屉自动滚到那一段并高亮

## 本地跑

双击 `启动.command`，自动开 `http://127.0.0.1:5199`。

或手动：

```bash
python3 -m http.server 5199 --bind 127.0.0.1
```

> `file://` 直接打开不行——`fetch` 会被 CORS 拦。

## 重新生成题库

```bash
node tools/fetch.mjs        # 抓 56 页（约 3 分钟，1.6s 间隔防限速）
node tools/parse.mjs        # 生成 data/papers.json + 校验报告
```

`parse.mjs` 会打印校验结果，全部通过才写文件。
