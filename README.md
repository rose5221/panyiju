# 判一句 · 考研英语一阅读 · 整篇训练

不做题海。一篇 5 题，一次练完一整套思路。

**纯静态站点**，无后端、无登录、无构建。记录存在浏览器 localStorage。

---

## 流程

严格按做卷子的顺序来。

```
① 看 5 个题干          ← 不读文章，先从题干推话题
   ↓ 三小步：扫重复名词 → 找态度线索 → 猜展开顺序
   ↓ 写一句"我猜这篇讲的是…"
② 读文章               ← 带着猜测读，可划线
   ↓
③ 做题                 ← 原文在上、题目在下
   ↓ 选一个选项
   ↓ ⚠️ 停住，必须写理由「我在第几段看到什么，所以选它」
   ↓ AI 检查理由站不站得住（不给答案）
   ↓ 理由写完才能进下一题
   ↓ （重复 × 5）
④ 交卷                 ← 对错表 + 你当初猜的主旨
   ↓
⑤ 逐题深度复盘         ← AI 拆出题人的坑
   ↓ 正确答案的替换链一步步摆出来
   ↓ 每个错项：出题人动了哪个词、改成什么、专骗哪种思路
   ↓ 你的理由错在哪一步
   ↓
⑥ 追问                 ← 哪个选项不懂就点它，问到懂
```

### 为什么是这个顺序

**先看题再看文** —— 题干里反复出现的名词就是话题，态度题暴露作者立场。带着假设读，比裸读快得多。

**选完必须停住说理由** —— 这是整套东西的核心。选对了说不清理由，是运气；选错了说得清理由，说明只是被干扰项骗了。理由会存下来，复盘时拿来对照。

**第几段那关删了** —— 太机械，没有训练价值。

**复盘不是罗列标签** —— 以前只告诉你"A 项无中生有"，那是流水账。现在 AI 要说清：出题人对原文做了什么手脚，这个坑专骗哪种思路，你的理由错在哪一步。

**追问** —— 看不懂就点那个选项直接问，AI 贴着你问的具体点答，答到懂为止。

## 本地跑

双击 `启动.command`，自动开 `http://127.0.0.1:5199`。

或手动：

```bash
python3 -m http.server 5199 --bind 127.0.0.1
```

> `file://` 直接打开不行——`fetch` 会被 CORS 拦。

---

## 重新生成题库

```bash
node tools/fetch.mjs        # 抓 56 页（约 3 分钟，1.6s 间隔防限速）
node tools/parse.mjs        # 生成 data/papers.json + 校验报告
```

`parse.mjs` 会打印校验结果，全部通过才写文件。

## 部署 GitHub Pages

```bash
git init && git add . && git commit -m "判一句"
git remote add origin git@github.com:<你>/<仓库>.git
git push -u origin main
```

Settings → Pages → Source 选 `main` / root。

> GitHub Pages 国内手机常打不开。想在手机稳定做题，建议同内容推 **Cloudflare Pages** 或 **Vercel**。
